# 평가 결과와 비교 조건

최종 보고서 §5.2·§5.3의 실험 결과와 §7.2의 한계를 기준으로 작성했습니다. 보고서의 초기 모델 설명과 최종 학습 설정은 구분하며, 최종 모델은 Qwen3-VL-8B입니다. 이 문서의 지표는 과거 실험 결과이며 2026.10.07에 재학습·재측정한 결과가 아닙니다.

## 7개 분류의 중간·최종 비교

| 실험 | 정확도 | Macro F1 | 평가 범위 |
| --- | --- | --- | --- |
| 템플릿 다양화 중간 실험 | 0.7086 | 0.6935 | 무증상·6개 질환, 700장 |
| 데이터 통합·단일 패딩 크롭 최종 실험 | 0.7400 | 0.7404 | 같은 평가 이미지, 700장 |

중간·최종에 같은 평가 이미지 파일을 사용했다는 점은 프로젝트 작성자의 후속 확인(2026.09.30)에 근거합니다. 보고서에는 중간 표의 안검염 행 누락이 있으나, 같은 절의 혼동행렬은 7개 클래스를 포함합니다. 중간 Macro F1은 그 혼동행렬 재계산값 0.69348257과 일치합니다.

학습 데이터 구성과 이미지 입력 방식이 함께 변경된 결과입니다. 중간 실험을 그 뒤에 시도한 원본+크롭 다중 이미지 실험과 동일한 실험으로 부르지 않으며, 패딩 크롭만의 독립 효과나 통계적 유의성을 주장하지 않습니다. 초기 4개 라벨의 결과와 최종 7개 라벨의 결과도 직접 비교하지 않습니다.

## 최종 클래스별 결과

보고서 §5.3의 표는 각 클래스 100장의 결과입니다. 클래스별 값은 보고서의 반올림 값을 사용하며 Macro F1은 전체 지표의 정밀도를 따릅니다.

유루증은 중간 표의 약 0.35에서 최종 약 0.48(본문 정밀값 0.4772)로 바뀌었지만 유사 병변과의 혼동은 남았습니다. 입력·데이터의 공동 변경 조건을 함께 설명합니다.

## 베이스라인과 그룹 통합 평가

| 모델 | 7개 분류 정확도 | 그룹 통합 정확도 |
| --- | --- | --- |
| ResNet50 | 0.79 | 0.944 |
| CLIP | 0.73 | 0.897 |
| PET-I | 0.7400 | 0.920 |

그룹 통합은 안검내반증·안검염·유루증을 하나로 취급하는 재평가입니다. 같은 그룹 안에서 세부 질환을 잘못 예측한 경우를 세부 분류와 다르게 집계하므로, 두 열은 서로 다른 평가 기준입니다. 그룹 결과를 세부 질환 정확도나 실제 임상 진단의 신뢰도로 치환하지 않습니다.

보고서의 베이스라인 비교는 팀 실험 결과입니다. 분류 정확도와 자연어 설명의 사실성·유용성은 서로 다른 평가 대상이며, 설명 품질의 별도 정량 평가를 수행한 것으로 쓰지 않습니다.

## 데이터와 학습 조건

- 원본 준비: AI Hub 반려견 안구 이미지 5,600장, 7개 분류 항목.
- 최종 팀 학습 형식: 진단 JSON 5,600개, 진단 Markdown 5,600개, 설명형 2,040개, 챗봇형 16,800개(§5.3).
- 최종 학습: A100 80GB PCIe 1대, 15,020 steps, 10시간 59분 13초. 보고서 환경은 Python 3.12.3·Linux 6.8.0.
- 설명형 생성 레포의 공개 CSV 3건·JSON 1건은 입력 형식 예시입니다. 최종 학습 세트·평가 세트의 전체 매핑이나 생성 실행 로그가 아닙니다.

학습·평가 분할의 전체 매핑, 각 형식의 필터 통과 건수와 데이터 누수 감사는 공개 코드만으로 새로 검증하지 않았습니다. 고정된 결과를 보장하는 재현 패키지로 해석하지 않습니다.
