# 평가 결과와 비교 조건

[프로젝트 소개](../README.md) · [실험 과정](DEVELOPMENT.md) · [최종 보고서](PETI_최종보고서.docx)

Qwen3-VL-8B 기반 최종 모델의 평가 결과입니다. 수치와 실험 조건은 최종 보고서 §5.2·§5.3, 한계는 §7.2에 근거합니다.

## 7개 분류의 중간·최종 비교

| 실험 | 정확도 | Macro F1 | 평가 범위 |
| --- | --- | --- | --- |
| 템플릿 다양화 중간 실험 | 0.7086 | 0.6935 | 무증상·6개 질환, 700장 |
| 데이터 통합·단일 패딩 크롭 최종 실험 | 0.7400 | 0.7404 | 같은 평가 이미지, 700장 |

중간·최종 실험은 같은 평가 이미지 700장을 사용했습니다. 보고서의 중간 결과 표에는 안검염 행이 빠져 있으므로, 7개 클래스를 포함한 혼동행렬을 함께 참고합니다. 혼동행렬에서 계산한 Macro F1은 0.69348257입니다.

최종 실험에서는 학습 데이터 구성과 이미지 입력 방식을 함께 변경했습니다. 이 비교는 두 변경의 종합 결과이며, 개별 효과를 분리한 통제 실험은 없습니다. 원본+크롭 다중 입력은 별도로 시도한 실험입니다. 초기 4개 라벨 실험은 분류 범위가 달라 위 비교에서 제외했습니다.

## 최종 클래스별 결과

보고서 §5.3의 표는 각 클래스 100장의 결과입니다. 클래스별 값은 보고서의 반올림 값을 사용하며 Macro F1은 전체 지표의 정밀도를 따릅니다.

| 클래스 | Precision | Recall | F1 | 평가 이미지 |
| --- | --- | --- | --- | --- |
| 무증상 | 0.91 | 0.93 | 0.92 | 100 |
| 결막염 | 0.80 | 0.82 | 0.81 | 100 |
| 궤양성각막질환 | 0.93 | 0.87 | 0.90 | 100 |
| 백내장 | 0.87 | 0.86 | 0.86 | 100 |
| 안검내반증 | 0.53 | 0.71 | 0.60 | 100 |
| 안검염 | 0.74 | 0.52 | 0.61 | 100 |
| 유루증 | 0.48 | 0.47 | 0.48 | 100 |

유루증은 중간 표의 약 0.35에서 최종 약 0.48(본문 정밀값 0.4772)로 바뀌었지만 유사 병변과의 혼동은 남았습니다.

## 베이스라인과 그룹 통합 평가

| 모델 | 7개 분류 정확도 | 그룹 통합 정확도 |
| --- | --- | --- |
| ResNet50 | 0.79 | 0.944 |
| CLIP | 0.73 | 0.897 |
| PET-I | 0.7400 | 0.920 |

그룹 통합은 안검내반증·안검염·유루증을 하나로 취급하는 재평가입니다. 이 세 질환 사이의 오분류도 같은 그룹 예측으로 집계하므로, 7개 세부 분류보다 완화된 평가 기준입니다.

베이스라인 비교는 팀 실험 결과입니다. 위 지표는 질환 분류를 평가하며, 생성 설명의 사실성·유용성은 별도의 품질 평가가 필요합니다.

## 데이터와 학습 조건

- 원본 준비: AI Hub 반려견 안구 이미지 5,600장, 7개 분류 항목.
- 최종 팀 학습 형식: 진단 JSON 5,600개, 진단 Markdown 5,600개, 설명형 2,040개, 챗봇형 16,800개(§5.3).
- 최종 학습: A100 80GB PCIe 1대, 15,020 steps, 10시간 59분 13초. 보고서 환경은 Python 3.12.3·Linux 6.8.0.
- 설명형 생성 레포에는 실행을 위한 CSV 3건·JSON 1건의 입력 예시를 제공합니다.

공개 레포에는 전체 학습·평가 분할 목록과 생성 실행 로그가 포함되어 있지 않습니다. 결과 재현에는 원본 데이터 분할·가중치·실험 환경을 별도로 준비해야 합니다.
